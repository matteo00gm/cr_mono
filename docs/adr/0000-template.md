# NNNN. Short noun phrase naming the decision

Status: Accepted
Date: YYYY-MM-DD

## Context

What forced a decision. The constraint, the pressure, the thing that would
otherwise have been chosen by default. Write what was true _at the time_ — this
section is never edited later, so it is a record of what was known, not of what
turned out to be so.

## Decision

What was chosen, in one or two sentences. Present tense, active: "The API runs
on Hono", not "We decided that we would use Hono".

## Consequences

What this costs, not only what it buys. A decision with no listed cost has not
been thought about — and the cost is what the next reader needs, because the
benefit is usually obvious from the decision itself.

## Alternatives rejected

Each with the reason it lost. This is the section that stops the same argument
being had again in a year, and it is the one most often skipped.
